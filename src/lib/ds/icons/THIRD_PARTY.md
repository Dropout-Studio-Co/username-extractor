# Icon provenance

The normalized `Moving` icons are source-copied from `jis3r/icons` version 2.9.0 via its
official per-icon shadcn-svelte registry/source-copy workflow. The reviewed source
snapshot is commit `dd0c44d3dcc318641fa755d981cfa6ba9b6a6e1f`; Dropout removed the
upstream self-hover wrapper, normalized props and semantics, and added the shared
reduced-motion contract. The upstream components are MIT licensed by jis3r. The
notice and license terms are retained here for the selected `ArrowUpRight`, `Bell`,
and `Settings` source.

Lucide remains the static icon language and is consumed through individual
`@lucide/svelte` imports. Brand and custom marks are Dropout-owned source.
